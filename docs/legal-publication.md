# AXON — интеграция юридических черновиков

Ветка legal-documents-preview от Stage 2.0 bdf7c47f07e0728b0746ca735627c7ca62730953. Только подготовка PR. Ни merge, ни deploy этим изменением не разрешены.

## Реализация
Шесть полных текстов из архива владельца, безопасный renderer без raw HTML/изображений/исполняемых ссылок, оглавления и связанные документы, версия/статус/дата, адаптивная типографика существующего Liquid Glass. Постоянные прямые пути зарегистрированы точным allowlist в Fastify, без широкого SPA fallback. Для черновиков noindex,nofollow и no-store. Футер содержит все документы.

Профиль Mini App ведёт в правовую информацию. Переходы по документам перехватываются только внутри активного Mini App без перезагрузки контекста; Telegram Back возвращает документ → список → профиль. Покупки/продления/поддержка/история не меняются. При недоступном API публичный текст остаётся читаемым.

В боте разделы кабинета/поддержки открывают «📄 Документы и условия». /terms и /legal показывают меню шести прямых ссылок; /paysupport сохраняет создание обращения. Баннерам, Premium emoji, main menu, токену и webhook изменения не требуются.
