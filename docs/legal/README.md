## Публикация
Все шесть записей в packages/shared/src/legal.ts — DRAFT, effectiveAt=null. Публичный /#/legal и API /api/v1/legal показывают только статус подготовки и DEMO-контакты; исходные черновики не обслуживаются как утверждённые документы. Прямой запрос draft body — 404.
После проверки: отдельный согласованный PR с окончательным текстом body, SHA-256 точных UTF-8 байтов, уникальной версией, APPROVED и реальной датой. Никакая env-переменная не утверждает документ. Предыдущие версии хранить неизменно в Git/архиве. Утверждение текста не включает коммерческие платежи автоматически.
LegalService требует точную версию и digest offer/agreement/payments для конкретного пользователя/заказа/канала, сохраняет неизменяемое подтверждение и дату. Это каркас доказательств, не заявление о достаточности акцепта для любой юрисдикции. Уведомление о privacy не смешивать с согласием на необязательную обработку/маркетинг. Новые требования к отдельным согласиям согласовать до LIVE.
