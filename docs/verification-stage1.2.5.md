## Ещё не подтверждено этим отчётом

Удалённый CI необходимо проверить на последнем коммите PR. Публикация feature-ветки не равна merge в main и deployment Render. Порядок выпуска описан в [cloud-deployment.md](cloud-deployment.md).

После выпуска владелец должен проверить настоящую Telegram-доставку, вход с компьютера через телефон, Android и iOS, работу на итоговом Render URL, одинаковый UUID при повторном входе и отображение прежних подписок. До этой проверки переход к Stage 1.3 остаётся отложенным.

При первом запуске тестовой Windows PostgreSQL прямой запуск был отклонён из-за административного token; штатный pg_ctl успешно запустил сервер с ограниченными правами. Первый интеграционный прогон поэтому не подключился к БД; последующие полные прогоны прошли. Обнаруженные при разработке ошибки типов, строгой JSON-валидации и сравнения requestId исправлены. Из оставшихся предупреждений — прежнее предупреждение зависимости Node о punycode; на результат тестов оно не влияет.
