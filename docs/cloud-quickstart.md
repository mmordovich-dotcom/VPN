# Как запустить Shared VPS Platform в интернете за несколько шагов

Всё делается через браузер. Терминал и установка программ не нужны.

1. **GitHub:** создайте репозиторий `shared-vps-platform`. Распакуйте ZIP и загрузите его содержимое в корень репозитория несколькими порциями, включая скрытую папку `.github`. Дождитесь зелёного **Actions → Verify foundation**.
2. **Neon:** создайте проект Free. В Connect возьмите direct-строку подключения и добавьте её в GitHub **Settings → Secrets and variables → Actions** под именем **NEON_MIGRATION_DATABASE_URL**. Строку никому не отправляйте.
3. **Создайте таблицы:** в GitHub Actions запустите **Cloud database - migrate and seed → Run workflow → main**. Дождитесь зелёного результата. Так появляются таблицы и Basic за 170 ₽.
4. **Render API:** создайте Free Web Service из того же GitHub-репозитория. Введите команды и переменные из [подробной инструкции](cloud-deployment.md). Строка Neon для API — pooled, с SSL. Получите фактический HTTPS-адрес API.
5. **Render сайт:** создайте Static Site, задайте **VITE_API_BASE_URL** равным полученному адресу API и запустите сборку. Адрес созданного сайта впишите в **CORS_ORIGINS** у API, сохраните и переразверните API.
6. **Проверьте:** сайт показывает DEMO MODE и Basic, `/ready` у API подтверждает доступ к базе. У обоих Render-сервисов должен быть режим **After CI Checks Pass**. Если использовали Blueprint — ещё выключите Auto Sync. Бесплатный API может просыпаться около минуты: подождите и нажмите «Проверить снова».

Начните с [подробного руководства](cloud-deployment.md): там точные поля, команды для вставки в Render, настройки безопасности, обновления и ошибки. Ничего не нужно вводить в локальный PowerShell/CMD.

Фактические публичные ссылки появятся только после вашего создания сервисов. До этого облачный запуск считается подготовленным, но не проверенным. Платежи, VPS и VPN не подключены. Перед подтверждением проверьте, что выбран Free; платные ресурсы не требуются этой конфигурацией.
