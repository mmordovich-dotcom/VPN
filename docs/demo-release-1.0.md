# AXON Demo Release 1.0 — критерии

Цель — публичное тестирование существующей демонстрационной платформы, не продажа настоящего VPN.

Готовность к согласованному выпуску: зелёные build/typecheck/unit/integration/Prisma/cloud/artifact/browser проверки для точного SHA; миграция проверена отдельно с сохранением данных; приватные поля скрыты; нет известных критических ошибок; актуальны инструкция, поддержка, диагностика, план восстановления и ограничения.

Готовность после публикации: /health и auth/config показывают 1.5, /ready подтверждает БД, фактический Render SHA записан, логи без критических ошибок, настоящий Telegram login и Mini App приняты владельцем, демо-покупка/продление/инструкция/поддержка проверены, Auto-Deploy восстановлен.

Ограничения: Render Free может засыпать, inline jobs и доставка продолжаются при работающем сервисе; 24/7 SLA нет. Новые Telegram сообщения проверяются автоматическим мок-транспортом до разрешённого production-теста. Android/iOS проверяются владельцем после выпуска. Диагностика инцидентов только DEMO, внешняя инфраструктура не опрашивается. Сетевую вместимость 4 не измеряли; разрешение выключено. Реального восстановления PITR и внешнего security audit в этом этапе нет.

До коммерческого использования нужны отдельные решения: письменные условия провайдера о модели третьих лиц, подтверждённые цены/лимиты/API, договороспособный оператор и применимая юрисдикция, правовая оценка разрешённого назначения, регистрация/налоги/учёт, оферта и правила сервиса, privacy/согласия/хранение/обращения, потребительские обязанности/компенсации, безопасность реальных платежей и нагрузки. Здесь они не реализуются. Реальные оплаты, VPS/VPN/Aeza остаются отключены.

Состояние фактических проверок: verification-stage1.5.md. Без отдельного разрешения владельца merge/deploy не выполняются.
