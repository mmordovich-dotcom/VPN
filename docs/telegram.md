# Один постоянный бот · AXON

Используется существующий @vpnaxon_bot и защищённый TELEGRAM_BOT_TOKEN. Site, API и webhook остаются в shared-vps-api; второй polling-бот не запускается.

Сохраняются шесть кнопок: Купить подписку, Моя подписка, Подключиться, Продлить подписку, Инструкции, Поддержка; также вход на сайт и получение кода. Stage 1.4 добавляет «Открыть приложение» / /app с inline web_app-кнопкой полного Mini App. Контекстные меню компактнее, статусы на русском, recovery-сообщения предлагают путь назад. Бот остаётся самостоятельным интерфейсом.

Покупка/продление показывают сумму и отдельное подтверждение, списание 0 ₽. Владение заказом, повторная операция и устаревшая кнопка проверяются прежним серверным кодом. Поддержка сохраняет ожидание текста в PostgreSQL; /start возвращает главное меню. В группах персональные операции не выполняются.

Уведомления доступны из подписки или /notifications; настройки общие с сайтом. Opt-in по умолчанию выключен. Актуальность, throttle, retry, blocked bot и неопределённые sends обслуживаются Stage 1.3 — [stage-1.3.md](stage-1.3.md).

Webhook проверяет secret header, сохраняет update до ответа, использует уникальный update_id, lease 60 секунд и до 5 попыток. Перед сетевой отправкой ставится send marker и 30-секундная lease. Неопределённая доставка и сбой DB acknowledgement после send карантинируются, автоматически не пересылаются. Коды/ссылки и отражённые Telegram credentials не записываются в durable response. Exactly-once внешней доставки не обещается.

При будущем старте Stage 1.4 bootstrap сверит username и текущий webhook, сохранит drop_pending_updates=false, затем задаст default menu AXON с корневым Mini App. Чужой webhook не заменяется. Protected ADMIN registration/status сохраняются. Bot API token не открывается в браузерном URL и не передаётся frontend.

Render Free спит без входящего трафика, поэтому ответы и уведомления могут задерживаться. Платный worker не создаётся. Настоящие сообщения и новое menu поведение проверяются владельцем при согласованном выпуске; тестовый transport в CI не объявляется настоящим Telegram.
