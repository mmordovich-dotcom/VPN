# Отчёт о реализации и проверке

Дата: 15 октября 2026. Это отчёт о фактически выполненных локальных проверках, а не подтверждение production-готовности.

## Передано

- Monorepo: четыре приложения (`api`, `bot`, `web`, `worker`) и четыре общих пакета (`database`, `shared`, `providers`, `runtime`).
- Fastify API: `/health`, `/ready`, `/api/v1/system/info`, дополнительный публичный read-only `/api/v1/plans`; CORS, безопасная обработка ошибок, конфигурация и завершение соединений.
- Prisma: 11 доменных таблиц, связи, enum, индексы, SQL CHECK, частичный уникальный индекс живой подписки на слот, триггеры ёмкости, начальная миграция и повторяемый seed Basic.
- Сайт: мобильная и настольная раскладка, светлая/тёмная тема, настоящий HTTP health и тариф из базы, загрузка/ошибки, честные сообщения о будущих функциях, изолированная страница будущей admin-панели.
- grammY: `/start`, четыре кнопки, API-клиент, обработка ошибок и отключение при пустом токене.
- Worker: проверка базы, отменяемый runner и корректное закрытие соединений; очереди и зарегистрированных задач пока нет.
- MockServerProvider: создание, чтение, завершение виртуальной записи и ошибки неизвестного ID; только память, без сетевых вызовов.
- Docker Compose, lockfile pnpm, CI-конфигурация и инструкции Windows/Linux/macOS.

## Фактически проверено

Среда: Windows x64, Node.js **22.22.2**, pnpm **10.34.4**, Prisma **6.19.3**, временная локальная **PostgreSQL 18.4**. Для этой проверки инструменты установлены отдельно от передаваемых исходников; данные тестовой БД и её случайный пароль не входят в архив.

| Проверка | Результат |
| --- | --- |
| Установка зависимостей из npm | Успешно |
| `pnpm install --frozen-lockfile --offline` с уже заполненным локальным кэшем | Успешно; lockfile согласован |
| `pnpm build` | Успешно для всех 8 workspace-пакетов/приложений |
| `pnpm typecheck` | Успешно, включая тесты, seed и служебные команды |
| `pnpm db:validate` | Prisma schema valid |
| `pnpm test` | **29/29**, 6 тестовых файлов, 0 ошибок |
| `pnpm test:integration` | **9/9**, 1 тестовый файл, 0 ошибок |
| `pnpm db:migrate` на пустой рабочей БД | Начальная миграция применена успешно |
| `pnpm db:seed` | Basic создан; повторяемость и сохранение изменённой цены дополнительно проверены тестами |
| `pnpm start:api` и HTTP сайта | API слушает 127.0.0.1:3000, сайт получает 170 ₽ / 30 дней через `/plans` |
| `/ready` с настоящей PostgreSQL | HTTP 200, проверено интеграционным тестом |
| `/ready` при ошибке БД | HTTP 503 с безопасным сообщением, unit-тест с инъекцией отказа |
| `pnpm dev:web` | Vite доступен на 127.0.0.1:5173 |
| `pnpm start:worker` | Подключение к PostgreSQL успешно, завершение с кодом 0 |

| `/start` и меню бота без сети Telegram | Реальные grammY-обработчики проверены через offline transport в unit-тестах |

Интеграционные тесты проверили миграцию в новой пустой схеме, seed дважды, отсутствие дубликата Basic, сохранение пользовательской корректировки цены, реальные `/ready` и `/plans`, уникальность identity и внешнего платежа, номера мест и уменьшение capacity, конкурентное назначение одного слота (один успех, один конфликт), повторное использование места с двумя сохранёнными записями истории, запрет удаления связанного слота, совпадение владельца заказа/подписки и проверки отрицательных сумм, дат и JSON-типов.

В браузере проверены ширина **337 px** и **1100 px** без горизонтального переполнения, обе темы, кнопка подписки, загрузка реального тарифа, страница `#/admin` без административных данных. API временно остановлен: кнопка повторной проверки показала «Нет соединения», после перезагрузки тариф показал ошибку загрузки. Отдельно наблюдалось состояние «Проверяем…»/«Загрузка тарифа…». Превью интерфейса приложено рядом с ZIP.

При финальной сборке обнаружена штатная блокировка загруженной DLL Prisma в Windows. После остановки тестового API полный набор команд успешно выполнен повторно; порядок действий документирован в README. grammY-зависимость выдаёт предупреждение Node о deprecated `punycode`; оно не мешает сборке и тестам.

## Что не проверено

- **Docker Compose и именно образ PostgreSQL 16.13**: Docker в среде отсутствует. Вместо контейнера использовался настоящий локальный PostgreSQL 18.4. Наличие Compose-файла не означает, что контейнер был запущен и проверен.
- **Живой Telegram polling с пользовательским токеном**: токен не предоставлен. Offline-тесты не заменяют эту проверку.
- **Linux/macOS и удалённый GitHub Actions**: инструкции и CI подготовлены, но в этом сеансе не выполнялись.
- Отправка сигналов завершения настоящему процессу на всех ОС и поведение при аварийном отключении питания: не проверялись отдельно. Закрытие HTTP/Prisma проверялось при завершении тестовых приложений.
- Нагрузочные испытания, длительная эксплуатация, полная матрица гонок и восстановление фоновых задач: относятся к следующим этапам.

Поэтому **полная приёмка Stage 1.1 пока не закрыта**. Исходники реализованы и перечисленные локальные проверки прошли; оставшиеся проверки Docker и Telegram нужно выполнить в подходящей среде по README.

## Ограничения и Stage 1.2

Нет настоящих оплат, аренды VPS, Aeza API, VPN, ключей доступа, пользовательской аутентификации, рабочего кабинета или административных операций. Mock-записи исчезают после завершения процесса; это явно демонстрационный адаптер. В Stage 1.2 предстоят заказы, идемпотентная обработка тестовых событий оплаты, атомарное выделение/освобождение мест, согласование статусов, durable jobs, ретраи и восстановление незавершённых операций. Платные интеграции в текущую реализацию не включены.
