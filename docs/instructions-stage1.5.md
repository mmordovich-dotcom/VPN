# Инструкции до и после оформления

Источник — packages/shared/src/release.ts. Встроенная копия позволяет открыть инструкцию без отдельного запроса к API; API /api/v1/instructions отдаёт те же данные. Общий текст используется Telegram-ботом.

До оформления: карточка тарифа обещает пошаговую инструкцию в кабинете и боте, содержит ссылку на инструкцию. Диалог подтверждения объясняет четыре следующих шага и нулевое списание.

После подтверждения сайт/Mini App открывает /checkout?order=… и проверяет GET /orders/:id. Успех возможен только при COMPLETED и действующей ACTIVE-подписке. Для PAID/PROCESSING — нейтральное ожидание, до 10 автоматических обновлений по 2 секунды и ручное обновление; для ошибки/отмены/истёкшего доступа — история и поддержка. Сетевой сбой не становится успешной активацией. Повторный заказ не требуется.

После успеха доступны «Открыть инструкцию», «Моя подписка», «Поддержка». В инструкции — выбор Android, iOS, Windows, macOS. Реальные шаги: открыть аккаунт, проверить статус/срок, посмотреть демонстрационный идентификатор, пользоваться AXON, при вопросе открыть поддержку. Идентификатор не импортируется в VPN-клиент. Установка ПО и изменение сети не предлагаются.

В боте сохранены кнопки «Инструкции», «Моя подписка», «Подключиться»; инструкция и платформы доступны в чате повторно. Сообщение об активации и необязательное уведомление заказа содержат кнопки инструкции/подписки/поддержки. Необязательные статусы учитывают прежние настройки уведомлений.

Реальный вход и действия в установленном Telegram на Android/iOS потребуют приёмки владельца после отдельно разрешённого выпуска. Симуляция SDK в браузерных тестах не заменяет эту приёмку.
